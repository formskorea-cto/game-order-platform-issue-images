# 경마게임2 Godot 자산 표시 보정 캡처

2026-10-20. `race2-android.png`와 GIF는 Android 에뮬레이터(SwiftShader) 화면입니다. `models-catalog.png`는 같은 로컬 GLB 팩토리를 Chrome에서 렌더한 10종 카탈로그입니다. 실물 태블릿 캡처나 실사 사진이 아닙니다. 선택 카드의 정적 미리보기는 Godot에서 렌더한 공유 이미지입니다.

기존 Godot 게임과 같은 동물·사람 자산을 재사용했습니다. 일부 자산은 단순화된 조형입니다. 캡처는 실사급 모델 제작이나 실물 GPU 성능 검증의 완료를 뜻하지 않습니다.
